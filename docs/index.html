Engineering choices
三个后端重点

      

        
01 / CONCURRENCY
租约 + fencing token
租约过期后新 Worker 获得更大的 token；旧 Worker 即使恢复，也无法提交过期写入。

        
02 / SIDE EFFECTS
UNKNOWN 需要对账
补丁写入后进程退出时，系统检查反向补丁和源码指纹。没有证据就不盲目重放。

        
03 / TRUST BOUNDARY
补丁不能修改验收规则
系统从 diff 独立提取路径，拒绝测试和验收器修改；独立验收命令不会进入 Repairer 输入或公开报告。
